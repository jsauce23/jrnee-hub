Website Hub API

A read-only API for your own website numbers — traffic, Google search performance, and form leads. Everything is JSON. Your key only ever returns your own data.

Keep your key on your server. Anyone who has it can read your data, so don't put it in a web page, an app, or anything a visitor could view the source of.

Getting started

JRNEE will give you a key that looks like jrnee_live_…. Send it with every request:

# check that your key works
curl https://YOUR-HUB-ADDRESS/v1/ping \
  -H "Authorization: Bearer YOUR_KEY"

A working key replies with your client name. Everything below uses the same header.

Endpoints

GET /v1/report

Everything in one call: traffic, where visitors came from, devices, top pages, Google search performance and a lead count.

QueryMeaning
days7, 28 or 90. Defaults to 28. Each number is also compared with the same length of time before it.

GET /v1/leads

Every form submission in the period, newest first. Only works if your key includes lead access.

curl "https://YOUR-HUB-ADDRESS/v1/leads?days=28" \
  -H "Authorization: Bearer YOUR_KEY"
{

GET /v1/ping

Confirms your key works and tells you whether it has lead access.

Responses

StatusMeaning
200Fine. If something upstream was unavailable, a notes field explains which part.
401Key missing or wrong.
403Your key can read numbers but not lead details.
429Over 120 requests in an hour. Wait and retry.

Things worth knowing

  • Numbers are cached for about 10 minutes, so calling more often won't get you fresher data.
  • Requesting every 15 minutes or so is plenty. Anything more just burns your rate limit.
  • Only GET is supported. This API reads; it never writes.
  • Your key is tied to one client. There's no way to reach another company's data with it.
  • Need a key rotated? Ask JRNEE and the old one stops working immediately.
